# Астро-Волга Такси

Самописный адаптивный лендинг для Луганска. Чистые HTML, CSS и JavaScript, локальные шрифты и изображения. Сборка и конструкторы не требуются.

## Состав

1. Главный экран с оригинальным креативом, номером и кнопкой пассажирского приложения.
2. Блок пассажиров с текстами, иллюстрацией интерфейса и кнопками Android / iPhone.
3. Блок водителей с приглашением к сотрудничеству и кнопкой водительского приложения.
4. Контактный подвал, мобильное меню, нижняя панель действий на телефонах, доступные уведомления.

Визуальный ориентир — https://astrovolga-zo.ru/: палитра, шрифт Open Sans и фирменный знак. Логотип и шрифты взяты с предоставленного заказчиком сайта. Городская иллюстрация с автомобилем сгенерирована специально для этого проекта. Город в креативе концептуальный. Интерфейс телефона является иллюстрацией, а не скриншотом существующего приложения.

## Просмотр

Откройте `dist/index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Затем откройте http://localhost:4173. Для обычного хостинга загрузите содержимое `dist` в корень сайта. Папка `.openai` нужна только для размещения на Sites.

## Настройки перед запуском

Все контакты и ссылки находятся в `dist/config.js`:

- `phoneDisplay` — отображаемый телефон.
- `phone` — настоящий телефон для звонка, например в международном формате с плюсом. Сейчас пустой.
- `address`, `email` — контактные данные.
- `passenger.android`, `passenger.ios`, `passenger.universal` — HTTPS-ссылки на пассажирское приложение.
- `driver.android`, `driver.ios`, `driver.universal` — HTTPS-ссылки на водительское приложение.
- `privacyUrl` — HTTPS-ссылка на утверждённую политику.
- `metrikaId` — номер счётчика Яндекс Метрики. Сейчас 0, поэтому аналитика не загружается.

Пока ссылки пустые, кнопки показывают уведомление и ничего не скачивают. Номер-заглушка не вызывает приложение звонков. Изначально у страницы установлен `noindex, nofollow`; при публичном запуске замените его на `index, follow`. Для социальных сетей укажите абсолютный адрес `og:image`. Утвердите тексты, контакты, условия сотрудничества и доступные платформы приложений перед запуском.

События Метрики, которые нужно создать как JavaScript-цели: `phone_click`, `passenger_app_click`, `driver_app_click`. У целей приложений есть параметры `platform` и `position`. События отправляются только при настроенных действующих контактах или ссылках. Эти цели измеряют нажатия и переходы, а не состоявшиеся звонки или фактические установки.

Тексты редактируются в `dist/index.html`, стили в `dist/styles.css`. Административная панель не входит в эту реализацию.
